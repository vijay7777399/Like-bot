RAILWAY TELEGRAM LIKE BOT - DEPLOY NOTES

FILES
- like_api_railway.py : bot source
- requirements.txt    : Python dependencies
- Procfile            : Railway worker start command
- .env.example        : example only; do not paste a real token here

RAILWAY SETUP
1. Upload these files to a GitHub repository. Do NOT upload a real bot token.
2. In Railway, connect the GitHub repository as a service.
3. In Railway > service > Variables, add:
   Name:  BOT_TOKEN
   Value: a NEW token generated by BotFather
4. Set the service start command to:
   python like_api_railway.py
   (or use the included Procfile worker command)
5. Deploy and inspect Deploy Logs.

IMPORTANT
- The token previously pasted into chat should be revoked in BotFather; use a new token.
- OWNER_ID is currently set to 8294478873 in the source. Change it if that is not your Telegram numeric user ID.
- The API URL is configured as:
  https://like-topaz-alpha.vercel.app/like?uid={uid}&region={region}&key=Anurag
- Runtime success depends on the API being online, accepting those query parameters, and returning JSON fields expected by the bot: status, PlayerNickname, UID, Server, LikesbeforeCommand, LikesafterCommand, LikesGivenByAPI.
- Python syntax was checked, but no one can guarantee zero runtime errors without testing against your live Railway variables and API.
